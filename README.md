# Lift – Suivi musculation

Application web installable (PWA) : suivi des séances, progression par exercice, programme A/B/C.

- Les données restent sur l'appareil (stockage local du navigateur). Sauvegarde / restauration via le bouton « Données ».
- Fonctionne hors ligne une fois ouverte une première fois.
- Installation : ouvrir le site sur le téléphone, puis « Ajouter à l'écran d'accueil ».
